# bash-practice


Учебный репозиторий по Bash для подготовки к DevSecOps

## Структура

- `day1/` — файлы и папки: touch, mkdir, cp, mv, rm, cat
- 'day2/' -grep, find, regular
- 'day3/' - права доступа
- 'day4' - процессы(практика, отчет в notes.md)
- 'day5' - ввод - вывод: >, >>, 2>&1
- `notes.md` — конспект по дням
